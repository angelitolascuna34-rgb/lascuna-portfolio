# Angelito Lascuna - Portfolio

A modern, responsive portfolio website showcasing my skills, projects, and experience in web development.

## 🚀 Features

- **Modern Design**: Clean, professional, and responsive layout
- **Hero Section**: Eye-catching introduction with call-to-action buttons
- **Skills Showcase**: Grid display of technical skills with icons
- **Projects Gallery**: Featured projects with links to GitHub repositories
- **Smooth Animations**: Fade-in and slide-in animations for visual appeal
- **Mobile Responsive**: Optimized for all device sizes
- **Dark Navigation**: Sticky navbar with smooth scrolling
- **Social Links**: Easy access to GitHub and contact information

## 📁 File Structure

## 🔧 How to Use

1. Clone or download this repository
2. Open `index.html` in your web browser
3. Customize content in the HTML file
4. Modify colors in CSS (root variables)
5. Update project links and information

## 📝 Customization

### Update Personal Information
Edit the following in `index.html`:
- Name and title in hero section
- About section content
- Project details and links

### Change Colors
Edit CSS variables in `styles.css`:
```css
:root {
    --primary-color: #2563eb;
    --secondary-color: #1e40af;
    --accent-color: #f59e0b;
    /* ... */
}
```

### Add New Projects
Add new project cards in the projects section following the existing structure.
